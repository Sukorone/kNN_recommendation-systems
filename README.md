# Система рекомендаций на основе k-NN

## Описание
Система рекомендаций, использующая алгоритм k-ближайших соседей (k-NN) для предсказания рейтингов пользователей.

## Установка зависимостей

### Автоматическая установка (Windows)
Запустите файл `install.bat`

### Ручная установка
```bash
pip install -r requirements.txt
```

### Проверка установки
```bash
python check_modules.py
```

## Запуск
```bash
python main.py
```

## Что делает программа
1. Создает тестовую матрицу рейтингов пользователей и товаров
2. Предсказывает рейтинги для неоцененных товаров
3. Выдает рекомендации пользователям
4. Оценивает качество системы по метрике Hit Rate

## Требования
- Python 3.7+
- pandas
- numpy
